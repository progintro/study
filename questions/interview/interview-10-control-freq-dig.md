Γράψτε μια συνάρτηση freq\_dig που παίρνει έναν δεκαδικό ακέραιο και επιστρέφει έναν πίνακα με τις συχνότητες κάθε ψηφίου (τον αριθμό των φορών που περιέχει κάθε ψηφίο). Για παράδειγμα, ο αριθμός 323210 θα επιστρέψει τον πίνακα {1, 1, 2, 2, 0, 0, 0, 0, 0, 0}. Η συνάρτηση μπορεί να έχει οποιαδήποτε διεπαφή (interface) επιθυμείτε.
