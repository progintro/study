Φτιάχνουμε το κείμενο ενός αριθμού ψηφίο-ψηφίο από το τέλος (`n % 10`), άρα στο τέλος
το έχουμε ανάποδα και πρέπει να το γυρίσουμε. Γράψτε μια συνάρτηση `reverse_string` που
αντιστρέφει ένα string **επί τόπου**: αλλάζει τους χαρακτήρες του ίδιου πίνακα, χωρίς νέα
μνήμη. Για παράδειγμα, μετά την κλήση σε `char s[] = "hello";` ο `s` είναι `"olleh"`.
Το κενό string μένει κενό. Το όρισμα είναι πάντα εγγράψιμος πίνακας (όχι string literal).
