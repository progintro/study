Γράψτε μια συνάρτηση reverse η οποία παίρνει ως όρισμα ένα string (char \*) και επιστρέφει το αντίστροφο. Για παράδειγμα, αν περάσουμε στην συνάρτηση το string “hello” περιμένουμε να μας επιστρέψει “olleh”.
