Ο αναδρομικός ορισμός των αριθμών Fibonacci γράφεται σε μία γραμμή, αλλά για `n = 50` δεν
τελειώνει ποτέ. Γράψτε μια συνάρτηση `fib` που παίρνει έναν ακέραιο `n >= 0` και επιστρέφει
τον n-οστό αριθμό Fibonacci **με βρόχο**, χωρίς αναδρομή. Εδώ `fib(0) = fib(1) = 1` και
`fib(n) = fib(n-1) + fib(n-2)`, δηλαδή η ακολουθία είναι `1, 1, 2, 3, 5, 8, 13, …`· για
παράδειγμα, `fib(5) == 8` και `fib(10) == 89`.

## Υπόδειξη

Δεν χρειάζεται πίνακας: αρκεί να θυμάστε τους δύο τελευταίους όρους και σε κάθε βήμα να τους «σπρώχνετε» μία θέση μπροστά. Προσέξτε τον τύπο: πόσο γρήγορα μεγαλώνει η ακολουθία και πού χωράει το `fib(50)`;
