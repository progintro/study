Στο Linux (σχεδόν) όλα είναι ένα:

- Ψέμα
- Αρχείο
- IP Address
- Κλικ

## Υπόδειξη

Θυμηθείτε τη φιλοσοφία του Unix για το σύστημα αρχείων: ακόμα και οι συσκευές εμφανίζονται κάτω από το `/dev`.
