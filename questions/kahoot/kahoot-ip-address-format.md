Ποια από τα παρακάτω αντιστοιχεί σε ένα IP address;

- 1.2.3
- 1.1.1.1
- A.B.C.D.E
- hello world

## Υπόδειξη

Μια διεύθυνση IPv4 γράφεται ως τέσσερις δεκαδικοί αριθμοί από 0 έως 255, χωρισμένοι με τελείες.
