```c
int x = 42;
if (x > 42)
    printf("Hello");
else
    printf("World");
```

## Υπόδειξη

Υπολογίστε τη συνθήκη `x > 42` για `x = 42` και θυμηθείτε ότι εκτελείται ακριβώς ένας από τους δύο κλάδους.
