Η συνάρτηση `getchar()` επιστρέφει μια τιμή τύπου:

- int
- double
- char
- Εξαρτάται

## Υπόδειξη

Εκτός από κάθε δυνατό χαρακτήρα, η `getchar` πρέπει να μπορεί να επιστρέψει και μια ειδική τιμή για το τέλος της εισόδου.
