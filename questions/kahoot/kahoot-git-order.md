Βάλτε τις ακόλουθες εντολές σε χρονολογική σειρά:

- `git push`
- `git commit`
- `git clone`
- `git add`

## Υπόδειξη

Ακολουθήστε τον κύκλο του git: πρώτα αποκτάτε αντίγραφο του αποθετηρίου, μετά ετοιμάζετε (stage) τις αλλαγές, τις καταγράφετε τοπικά και στο τέλος τις στέλνετε στο GitHub.
