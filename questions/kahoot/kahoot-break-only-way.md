Η εντολή `break` είναι ο μόνος τρόπος για να σταματήσουμε έναν βρόχο;

- True
- False

## Υπόδειξη

Σκεφτείτε πώς τελειώνει ένας συνηθισμένος βρόχος `for (i = 0; i < 10; i++)` και τι άλλο είδαμε, π.χ. μεταβλητές-σημαίες ή `return`.
