Ο πιο αποδοτικός τρόπος για να αντιγράψω έναν πίνακα 100 στοιχείων είναι με ανάθεση:

```c
int a[100];
int b[100];
b = a;
```

- True
- False

## Υπόδειξη

Μπορεί ένα όνομα πίνακα να βρεθεί στα αριστερά μιας ανάθεσης;
