Το `struct node {int x; struct node *next;}` είναι δομικό στοιχείο για:

- union (ένωση)
- binary tree (δυαδικό δέντρο)
- single linked list (απλά συνδεδεμένη λίστα)
- graph (γράφος)

## Υπόδειξη

Κάθε κόμβος δείχνει σε έναν μόνο επόμενο κόμβο· τι σχήμα φτιάχνουν τέτοιοι κόμβοι αν τους αλυσοδέσετε;
