Ποιες από τις ακόλουθες είναι εντολές git; (Μπορεί να είναι σωστές περισσότερες από μία.)

- `git push`
- `git status`
- `git gud`
- `git commit`

## Συχνή παρανόηση

Το 35% διάλεξε μόνο `git push` και `git commit`, ξεχνώντας το `git status`, που δεν αλλάζει τίποτα αλλά δείχνει ποια αρχεία έχουν αλλάξει ή είναι staged.

## Υπόδειξη

Σκεφτείτε όχι μόνο τις εντολές που αλλάζουν το αποθετήριο, αλλά και εκείνη που τρέχουμε συνεχώς για να δούμε σε ποια κατάσταση βρίσκονται τα αρχεία μας.
