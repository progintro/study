Έστω ότι η τιμή του δείκτη `int *ptr` είναι 42. Η τιμή του δείκτη `(ptr + 1)` είναι:

- `43`
- `46`
- `42`
- Εξαρτάται

## Υπόδειξη

Πόσα bytes προχωράει ένας δείκτης σε `int` όταν του προσθέτουμε 1, και είναι αυτό το ίδιο σε κάθε σύστημα;
