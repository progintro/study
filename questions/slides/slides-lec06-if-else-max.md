Δίνεται ο κώδικας:

```c
if (x > y)
    max = x;
else
    max = y;
```

- Θα μπορούσαμε να "ζήσουμε" χωρίς `else`;
- Υπάρχει εναλλακτικός τρόπος να γράψουμε το παραπάνω;
- Τι κάνουμε όταν έχουμε πάνω από δύο συνθήκες;

## Υπόδειξη

Για το πρώτο ερώτημα, σκεφτείτε τι θα γινόταν αν δίνατε μια αρχική τιμή στο `max` πριν από την `if`. Για το δεύτερο, θυμηθείτε τους τελεστές της προηγούμενης διάλεξης: υπάρχει ένας που επιλέγει ανάμεσα σε δύο τιμές μέσα σε μία έκφραση. Για το τρίτο, σκεφτείτε τι επιτρέπεται να είναι η εντολή μετά το `else`.
