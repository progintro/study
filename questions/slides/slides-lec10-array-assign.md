Μπορώ να αναθέσω τα στοιχεία ενός πίνακα σε άλλον;

```c
int a[3] = {1, 2, 3};
int b[3] = {4, 5, 6};
b = a;
```

## Υπόδειξη

Δοκιμάστε να το μεταγλωττίσετε με `gcc`. Αν δεν επιτρέπεται, πώς θα αντιγράφατε τα
στοιχεία;
