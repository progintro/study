Η αρχιτεκτονική ενός υπολογιστικού συστήματος περιγράφεται από την αλυσίδα:

```text
Users / Χρήστες --(Χρησιμοποιούν)--> Applications or Programs / Εφαρμογές ή Προγράμματα
  --(Χρειάζονται)--> Operating System / Λειτουργικό Σύστημα --(Χρειάζεται)--> Hardware / Υλικό
```

Παραδείγματα;

## Υπόδειξη

Για κάθε κουτί της αλυσίδας σκεφτείτε κάτι που χρησιμοποιείτε καθημερινά: ποιες εφαρμογές ανοίγετε, σε ποιο λειτουργικό σύστημα τρέχουν και σε ποιες συσκευές.
